# 민병희

러닝 앱 **러닝그라운드**를 만들고 운영합니다. React Native와 Node.js로 앱부터 백엔드,
네이티브 모듈까지 직접 씁니다.

관심 있는 문제는 대체로 **"왜 두 기기가 다른 답을 내는가"** 쪽입니다 — 실시간 동기화,
백그라운드에서의 기록 유실, 플랫폼 간 측정 불일치 같은 것들.

---

### 지금 만들고 있는 것

**🏃 [러닝그라운드](https://github.com/Min-heee/running-ground)** — 러닝 앱 · 운영 중

혼자 달리기, 실시간 1:1 대결, 파티런, 경찰과 도둑런, 지역 랭킹, 포인트 경제.
앱 88,000줄 + 백엔드 24,000줄, 화면 34개, iOS/Android 네이티브 모듈 포함.

*코드는 비공개(운영 중 서비스). 저장소에는 아키텍처와 **엔지니어링 사례연구 4편**이 있습니다 —
실시간 거리 동기화가 얼어붙던 문제, 화면을 끄면 기록이 사라지던 문제 같은 것들의 근본 원인 추적기.*

**🔭 [러너의 우주](https://github.com/Min-heee/runner-universe)** — 3D 웹 사이트 · **코드 공개**

달린 거리를 천체로 읽습니다. 러너 한 명이 행성 하나, 지역 하나가 은하 하나.
층을 갈아끼우지 않는 하나의 연속 공간이고, 이미지 에셋 없이 텍스처를 전부 코드로 만듭니다.

`three.js` · `React` · `Vite` — 원래 러닝그라운드의 탭이었는데 웹으로 독립시켰습니다.

**🧮 정산야호** — 모임·여행 정산 앱 · TestFlight

차수가 이어지고(1차 카페 → 2차 밥 → 3차 술) 차수마다 결제자가 다르고 항목마다 먹은 사람이
달라도, **최소 송금 횟수**로 정산합니다. 여행에서는 지출마다 통화가 달라도 원화로 환산해
한 번에 끝냅니다.
