# 민병희

바이브코딩으로 필요한 서비스를 빠르게 만들고, 직접 써 보며 다듬어 가는 개발자입니다.
AI 코딩 도구(Codex·Claude Code)와 함께 기획부터 출시·운영까지 합니다.

**포트폴리오 사이트:** https://minbyounghee.vercel.app — 프로젝트를 화면 사진과 쉬운 설명으로 모아 두었습니다.
