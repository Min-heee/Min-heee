# 민병희

병원 직원이 환자 문의에 답하고 수술 뒤 다시 연락하는 수고를 덜어 주는 도구와, 혼자 운영하는 러닝 앱을 만듭니다.
무엇을 만들지와 판단 기준은 제가 정하고, 코드는 AI 코딩 도구(Claude Code)와 함께 씁니다.

병원 도구 셋은 가상 의원과 지어낸 데이터로 만들었고, 실제 병원에서는 아직 써 보지 않았습니다.
러닝그라운드 저장소에는 상대 거리가 90초 넘게 멈추던 문제의 원인(3MB로 부푼 서버 데이터)을 찾아 고친 기록 등 사례연구 4편이 있습니다.
